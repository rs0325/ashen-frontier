# 素材の作り方【確定】

## テクスチャ

- テクスチャはGPT-imageで生成する。
- 基本解像度は16×16とし、精密に描きたい一部の機械などは32×32または64×64とする。
- 規則的な模様などコードで生成できる素材はコードで作る。
- それ以外はGPT-imageが公式に対応する解像度（1024×1024など）で出力してから、コードで目的のピクセルサイズに変換する。直接小さい解像度で生成すると失敗しやすいため。
- 変換などの具体的な手順は、実装時に最適な方法を調査して決める。
- インゴットなどバニラと規則をそろえる素材は、バニラと同系統の見た目にそろえる。ただし、バニラの素材そのものは複製しない。
