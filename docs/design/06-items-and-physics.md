# アイテムの性質と物理モデル（確定・一部案）

## アイテムの性質【確定】

アイテム種別に固定の値は**材料データ**（データマップ）、個々のアイテムで変わる値は**データコンポーネント**で持つ。

| 性質 | 持ち方 | 内容 |
|---|---|---|
| 質量 | 材料データ | 運搬負荷の計算に使う（kg） |
| 硬度 | 材料データ | 道具と対象の硬度差で、採掘の可否・速度・摩耗を決める |
| 密度・比熱・融点・熱伝導 | 材料データ | 加熱・冷却・鋳造の計算に使う |
| 摩耗 | コンポーネント | 耐久値の拡張。研ぎ・修理で回復し、修理のたびに上限が少し下がる |
| 温度 | コンポーネント | 加熱した金属など。最後に計算した時刻と温度から、周囲温度へ冷める様子を必要時に計算する |
| 組成・純度・品質 | コンポーネント | 金属・化学物質・化石燃料。品位によって後の工程の歩留まりが変わる |
| 栄養 | 材料データ＋コンポーネント | エネルギー・たんぱく質・脂質・ビタミン類・水分 |
| 腐敗 | コンポーネント | 作成時刻と保存温度から必要時に計算する。冷暗所・塩漬け・乾燥・缶詰で遅らせる |
| 汚染 | コンポーネント | 汚染土の作物・感染動物の肉など。摂取・接触で中毒・感染の要因になる |
| 放射能 | 材料データ＋コンポーネント | 代表核種と放射能（Bq）。半減期による減衰を時刻から必要時に計算し、線量率の計算に使う |

- **シリーズごとの性質:** アイテムやシリーズを追加するときは、必要な性質を提案に含めて定義する（例: 電池＝化学系・容量（J）・充電量・自己放電・充放電回数による劣化）。
- **スタックの扱い:** 温度・腐敗・組成などの値を段階に丸めて同じ段階なら重ね、重ねるときは不利な側に寄せる。
- **表示:** 個人端末の拡張状況に応じて、ツールチップに出す情報を増やす。

## 物理モデル

内部はSI単位で持つ。各モデルは「ネットワーク（同じ系につながったブロック群）」単位で計算し、構成が変わったときに再解析する。

### 回転動力（kinetics）

- 軸・歯車でつながったネットワークごとに、回転数（rad/s）とトルク（N·m）を持つ。仕事率 P = τω。
- 歯車比で回転数とトルクを変換する。消費機械は必要なトルク・回転数の範囲を持ち、供給が足りなければ遅くなる・止まる。
- 摩擦損失はネットワークの規模に応じて差し引く。

### 熱と蒸気（steam）

- ボイラーは水の質量・温度・圧力を持つ。飽和蒸気の圧力と温度の関係は、蒸気表（IAPWS-IF97）から作った参照表で求める。
- 燃料の発熱量（J/kg、化石燃料は品質で変わる）と効率から加熱量を、外気温・断熱から放熱量を計算する。
- 安全弁の設定圧を超えると蒸気を逃がす。
- 蒸気機関は蒸気の圧力・流量から回転動力へ変換し、復水・排気の扱いで効率が変わる。

### 設備の破損【確定】

- 破損は管理を怠った場合（整備不足、定格を超えた運転、安全装置の欠如）にだけ起き、適切に管理すれば起きない。
- 技術が進むと、自動制御・安全装置・耐久性の高い材料で、そもそも破損が起きない設備を作れる。
- 被害は設備本体と周辺に限り、地形を大きく壊さない。過負荷の機械は止まるだけにする。

### 流体と配管

- 配管ネットワークごとに圧力と流量を近似計算する（ポンプの揚程、配管の抵抗、高低差）。流体は質量で保存する（増殖しない）。
- **多チャンネル配管【確定】:** 1ブロックに通せる配管の数を技術で増やせる（1→4→16チャンネルの3段階）。チャンネルを増やすと1本あたりの管径が小さくなり、流量が落ちる。
  - 管径による流量の低下は現実の関係（層流ではハーゲン・ポアズイユの式で管径の4乗に比例、乱流ではダルシー・ワイスバッハの式）に基づいて近似する。
  - 低下は配管自体の性能（耐圧による高圧運転、内面の粗さ、耐食性・耐熱性）の向上で補う。これを配管の発展の軸にする。

### 物質収支

- レシピは入力と出力の質量の釣り合いを目安にする（副産物・損失を出力として明示する）。
- 化学反応は速度論を持たず、温度・圧力・触媒・時間を条件として扱う。

## レシピ【確定】

- coreの共通レシピ形式で、温度範囲・圧力・時間・エネルギー・触媒・必要設備を条件として持つ。
- 作業台（クラフトグリッド）は単純な組み立てに限り、加工は設備で行う。
- **バニラのレシピを大きく改変する:** 現実の製法に近づける。
  - 例: ピッケルは素材を並べるだけでは作れない（石器は打製・柄の取り付け、金属は製錬・鍛造が必要）。
  - 例: バケツは金属を薄く伸ばす加工（手作業の鍛造、後に圧延機）をしないと作れない。
- **素手で壊せるブロックを限る:** 土・砂・葉などの柔らかいものだけにし、木・石などは道具が必要。
- JEI・EMIでは条件を含めて表示する。研究で未解放のレシピは「未解放」として表示し、解放条件を見られるようにする。

## 搬送【確定】

- バニラのホッパーは削除する。
- 自Modの搬送手段（シュート、コンベア、後に空気輸送・鉄道など）と仕分け機を段階的に用意する。

## 交配【確定】

- 作物（と家畜）は形質（収量、生育期間、乾燥・寒冷・塩類・汚染への耐性など）を種子・個体のコンポーネントとして持ち、交配で受け継がせる。
- 高い水準の品種は、温室・環境制御などの科学技術がないと交配・栽培できない。
- 遺伝の規則（優性・劣性、形質の組み合わせ）の詳細は【案】として農業の提案パッケージで設計する。

## 武器【確定】

- 銃を追加する。弾薬は自力で製造でき（火薬は硝石・硫黄・木炭から作る）、技術の発展で前装式から後装式・金属薬莢へ進む。
- 旧文明の銃は残存物資として見つかるが、弾薬・修理部品は希少で、自力製造できるようになってから本格的に使える。
- **段階:** Tier 1で黒色火薬の前装式、Tier 2で工作機械による後装式・金属薬莢。
