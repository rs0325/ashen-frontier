# 第1期: 蒸気文明まで（確定）

## 目標

Tier 0〜2（生存基盤〜蒸気文明）を遊べる状態にする。ワールド生成で配置される物は全Tier分をcoreで登録するため、マップと遺物は第1期で全域を作る。

## 最序盤の考え方

- **石器時代の記録を参考にする:** 打製石器（礫器から両面加工の石器へ）、柄の取り付けと紐（植物繊維）、摩擦による火起こし、土器など、考古学で確認されている技術と順序を基準にする。
- **初期の水・食料:** 初期シェルターと周囲の建物に、比較的安全な食料・水を置く。
- **水の自給:** 汚染の少ない水を、沈殿・布・砂でろ過し、火で煮沸する。低効率で、重金属・塩類・多くの化学物質は除けない（[03](03-world.md)の水の汚染段階）。
- **食料の自給:** 初期シェルター内の小規模な栽培室で、種子・菌類を育てる。
- **電力不要の水の生産:** 低効率だが電力なしで水を作れる設備を用意する。
  - 手動ポンプ（地下水の汲み上げ）
  - 太陽熱蒸留器
  - 燃料を使う蒸留器
  - 雨水回収設備

## マイルストーン

各マイルストーンは社内の区切りで、公開しない。ある程度完成した時点で公開する。

| # | マイルストーン | 完成条件 |
|---|---|---|
| M1 | 共通基盤 | coreの基盤一式が動き、JEI・EMIで空のレシピ型が表示される。互換性チェック・救済コマンド・チーム・バニラ要素の削除が動く |
| M2 | 固定マップ | 地形・地域・水・土壌・地質・地下構造が生成され、主要施設と初期シェルターが配置される |
| M3 | 気候と生存 | 気候・気象と第1期の生理・感染症が動き、序盤地域の敵が出て、初期シェルターから生存できる |
| M4 | Tier 0 | 石器・火・水の自給・栽培・調理で安定した生活ができる |
| M5 | Tier 1 | 回転動力と搬送で加工できる |
| M6 | Tier 2 | 製錬・鍛造・蒸気機関・工作機械で金属部品を自力製造でき、銃と弾薬を作れる |
| M7 | 移動手段 | 蒸気車両・蒸気機関車と旧鉄道の修復 |

各マイルストーンの中身（アイテム・ブロック・レシピの一覧）は、着手前に提案パッケージとして提示し、承認後にIssueへ分ける。
