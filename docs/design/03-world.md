# ワールド（確定）

[09](09-open-questions.md)のF節は回答済み。M2の配置・生成方式の正本は[12-m2-fixed-map.md](12-m2-fixed-map.md)とし、他大陸等の役割・具体的配置は同書の「未決定（後で決める）」に従う。未決定の内容を確定済みとして配置しない。

## 固定マップの方式【確定】

- バニラのオーバーワールド生成を独自の生成器で完全に置き換える。
- **地形は全ワールド共通:** 地形・地域・主要構造物はワールドのシードに依存させない。建物の室内配置、小規模な痕跡、ルートの細部だけをワールドのシードでランダムにする。
- **生成のタイミング:** 全域を事前生成せず、プレイヤーの探索でチャンクが読み込まれた時点で、固定の配置データと決まった内部シードから決定的に生成する。
- **作り方:** 低解像度のラスターデータ（1ピクセル＝16ブロック、2,048²ピクセル）として、標高・地域・河川・海岸線・主要構造物の配置図を同梱し、決まった内部シードのノイズで細部を補う。
- **配置図の作成:** 参考図に基づく大まかな陸海マスクと、承認済みの地域配置・山脈・流域の制約を`tools/`の生成ツールへ入力する。海岸線の細部・小島・河川等を決定的に補い、構造物の位置・向きは配置図で調整する。詳細は[12](12-m2-fixed-map.md)を参照。
- **マップ案の提示:** GPT imageで概略図を示す。生成画像内の座標・距離・縮尺は正確な値として扱わず、配置図ツールで確定・検証する。
- **マップの更新:** マップ版で管理し、主要構造物の変更は新規ワールドだけに反映する。リリース後の構造物の変更は可能な限り避ける。

## 規模と緯度【確定】

| 項目 | 値 | 理由 |
|---|---|---|
| 大きさ | 32,768 × 32,768ブロック（中心±16,384） | 徒歩で端から端まで約2時間。鉄道・車両の価値が高い |
| 南北 | 北端80°N〜南端80°S（約1°＝205ブロック） | 両端の凍土・氷河、中緯度の温帯、赤道付近の熱帯・乾燥帯を1枚に収める |
| 東西 | 経度の概念は持たない | 簡略化 |
| 高さ | バニラと同じ（Y −64〜320） | 高さを広げると負荷が増える |
| 仮想標高 | 海面Y=63を0 mとし、1ブロック≒25 mで換算 | 気温減率・気圧・酸素分圧の計算に使う |

- **気温の分布:** 現実と同じく南北の端ほど寒く積雪・凍結し、赤道付近は灼熱になる（[04](04-climate.md)）。
- **ワールドの端:** ワールドボーダーで区切り、端に近づくほど濃くなる霧（砂塵・吹雪など地域に合う表現）で外側を見えなくする。
- **バイオームの霧:** 端の霧の遷移幅は約1,024ブロックで、端より手前で不透明になる。端以外もバイオームごとに静的な霧・砂塵の濃さと色を持たせ、全体に濃いめとしつつ空気のきれいな例外も認める。M2はworldが静的設定、M3はclimateが時間変化を担当し、重い粒子は設定で削減できる（[12](12-m2-fixed-map.md)）。

## 旧文明の痕跡【確定】

- **大規模施設:** 位置・構造を固定する（マップ版で管理）。一般建物・室内は部品の組み合わせで生成し、小さな痕跡は地域ごとの規則で散布する。小規模な痕跡・建物の実際の配置は必要になった時点でユーザーへ確認する（[12](12-m2-fixed-map.md)）。
- **構造物の作成:** 大規模施設・初期シェルター・一般建物は、再配布・改変を許可された外部素材を基本とし、必要な場合にまれに自作する。素材を選定・改変・変換し、一般建物は部品の組み合わせで生成する。
- **構造物データの取り出し:** 1.21.1のバニラ構造物NBT（ストラクチャーブロックは1つあたり最大48³）、Sponge v3の`.schem`、1.21.1の`.mca`を取り込む。v2以前の形式はWorldEditでv3へ保存し直してから取り込む（[12](12-m2-fixed-map.md)）。
- **変換と配置:** `tools/`の変換ツールでModが読み込む形式へ変換し、ブロックの置き換えも行う。固定マップの生成で決めた座標に配置する。48³を超える構造物は自動で断片に分け、チャンクをまたいで配置する。
- **配置時の処理:** バニラの構造物プロセッサで、ブロックを劣化した状態へ確率的に置き換え、一部を崩落させ、チェストに地域別ルートを入れる。
- **外部構造物の利用:** 作者・配布元・ライセンス・再配布/改変条件・必要な表示を記録し、権利条件が不明な物は同梱しない。Modのブロックが必要な箇所は、バニラの仮ブロックを変換時に独自ブロックへ置き換える。
- **遺物の中身:** 旧文明は土星圏まで進出した技術水準のため、残っている物の多くは序盤にそのまま使えない。
  - **発展後に使える物:** 工業部品・化学物質（電池、電子部品、触媒、高純度の試薬、合金材など）。必要な技術を得てから使える・修理できる。序盤は分解して素材にすることだけできる物もある。
  - **生活に自然な物:** 食料・缶詰、衣類、日用品、簡単な工具、医薬品など。序盤から使える。
- **回収と修復:** 設備は「回収（分解して部品・素材を得る）」と「修復（必要な技術・部品・動力が揃えば再稼働）」の2通りで使える。第1期では高Tierの設備は回収だけ可能にする。
- **有限性:** 遺物は有限で、進行に必須の物は再製造の手段を必ず用意する（[07](07-progression.md)）。

## 地下【確定】

- 旧文明の地下構造（地下鉄、地下街、坑道、地下保管庫、シェルター、配管・ケーブルの共同溝）を残す。
- 鉱物は**鉱床**としてまとまった位置に配置し、探査（露頭、試掘、後に物理探査）で見つける。鉱床以外の岩盤にはほぼ何もないため、当てずっぽうの長時間採掘（ブランチマイニング）の価値は低い。
- バニラの鉱石は、特定の鉱床に少量・局所的にだけ生成する。
- 岩石の硬さで掘る手間が変わり、大規模な掘削は道具・機械の発展で効率化する（手作業の選別や長時間の採掘をプレイの中心にしない）。

## 初期スポーン【確定】

- 初期スポーン地点は北西大陸中央の北緯40°に置く。各地域の配置と距離は[12-m2-fixed-map.md](12-m2-fixed-map.md)を参照し、正確な座標は陸海マスク作成時に決める。
- 初期生存地域の市街地にある、スポーン専用の小型地下シェルターに固定する。
- シェルターと周囲の建物に、比較的安全な食料・水を置く。必須物資はプレイヤーごとに配布する。
- シェルター内には、旧文明の技術による小規模な**栽培室**（安全な土壌と少量の水で種子・菌類を育てられる）があり、序盤の自給の起点になる。
- 周辺の市街地で、序盤の素材（金属くず、木材、布、ガラス）を確保できる。
- 最初の道具用の礫・火打石・枯れ枝・植物繊維を、道具なしで集められる形で周辺に保証し、初期配布にも簡易工具を入れる（[06](06-items-and-physics.md)、[12](12-m2-fixed-map.md)）。
- 建物内の食料・水分等の消耗品は、初回開封時にサーバー設定の倍率で数量を調整する。個人別の初期配布は対象外とし、低倍率でも必須物資・資料を保証する。開封済みの中身には再適用しない（[12](12-m2-fixed-map.md)）。

## 水【確定】

- **無限水源:** ゲームルール`waterSourceConversion`を既定で無効にし、水源の増殖を止める。例外は海だけで、海は無限とする。
- **海:** 海水は高い段階まで汚染されており、飲用・工業用にするには高度な処理が必要になる（海の無限性で序盤の水問題が解決しないようにする）。危険な海洋生物が出る。
- **淡水の入手:** 河川・湖（有限）、雨水の回収、地下水（井戸・手動ポンプ）、雪氷の融解、太陽熱・燃料による蒸留、後に淡水化。
- **地下水:** 地域ごとに帯水層の容量と涵養量を持たせ、汲み上げすぎると水位が下がり、時間で回復する。気象セル単位で集約して計算する。M2のworldは帯水層・水域の初期データ、M3のclimateは残量・涵養・水位の時間変化を担当する（[12](12-m2-fixed-map.md)）。

### 水の段階【確定】

水は段階ごとに別の流体として扱う（流体ごとに飲用・工程での可否が決まる）。段階は今後追加することがある（追加時は提案パッケージに含める）。

| 段階（en_us） | 主な汚染 | 処理 |
|---|---|---|
| 超純水（Ultrapure Water） | なし（イオン・微粒子・有機物・溶存ガスも極めて少ない。比抵抗18.2 MΩ·cm（25 ℃）が理論上の上限） | 純水を逆浸透・電気脱イオン・紫外線酸化・精密ろ過で多段処理。電子部品・半導体の製造に使う |
| 純水（Pure Water） | なし（溶存イオンをほぼ除去） | 清浄水を蒸留・イオン交換で処理。化学の試薬・分析、ボイラー給水、電池の電解液に使う |
| 清浄水（Clean Water） | なし | そのまま飲める。溶存する塩類（硬度成分）を含み、ボイラーで使うとスケールが溜まって効率が落ちる |
| 生水（Raw Water） | 微生物 | 煮沸で清浄水 |
| 濁水（Turbid Water） | 微生物・懸濁物 | 沈殿・布・砂でろ過→生水 |
| 汚染水（Contaminated Water） | 重金属・塩類・化学物質 | 蒸留で清浄水（ろ過・煮沸では除けない） |
| 有毒水（Toxic Water） | 高濃度の化学物質・放射性物質 | 化学処理・イオン交換など中盤以降の技術 |
| 汚染海水（Polluted Seawater） | 塩類・重金属・化学物質 | 前処理＋蒸留・淡水化。海水からの製塩も中盤以降 |

原始的な処理（沈殿・布・砂のろ過、煮沸）は低効率で、重金属・塩類・多くの化学物質は除けない。

## 土壌【確定】

土の質（肥沃土・土・痩せ土・劣化土）と汚染を分ける。汚染は重金属・有機化学物質・塩類・酸性・放射性物質・生物の6種類が重なり、種類ごとに清浄・軽度・中度・高度・有毒の5段階を持つ。旧汚染土・有毒土IDを廃止する（未リリースにつき旧ワールドは再生成）。

対象はバニラを含む土・砂・砂利・泥・粘土・泥炭・堆積物・薄層。岩・人工物・流体は対象外。内部量はPb/PCB換算kg/kg、ECe S/m、pH、Cs-137 Bq/kg、糞便性大腸菌群MPN/kg。閾値・一次出典・固定分布・深さ減衰・保存・持ち運び・表示は[12の#79確定仕様](12-m2-fixed-map.md#ブロックの汚染79、2026-11-23確定)を正本とする。清浄は無菌や食品の安全基準を意味しない。

拠点周囲の清浄円と入口の予備土は設けず、栽培室の清浄な肥沃土と旧農業西256×256の清浄予備地で詰みを防ぐ。M2では測定・配置・持ち運びだけを行い、作物移行と曝露はM3/M4、浄化・中和はM4以降に設計する。

## 地質と資源

- **地層と岩石:** バニラにある岩石（花崗岩・閃緑岩・安山岩・凝灰岩・深層岩・玄武岩・方解石・砂岩など）を使う。地質の設計に必要でバニラにない石灰岩・頁岩などの岩石は独自に追加し、coreで登録する。地域ごとに岩石の種類と地層を持たせ、鉱物資源は母岩と結び付ける（例: 石灰岩地域の鉛・亜鉛、塩基性岩の銅・ニッケル）。
- **必須資源の保証:** 進行に必須の鉱床は固定位置に必ず置き、到達可能にする。それ以外は決定的ノイズで配置する。
- **母岩別の鉱石:** 実際の鉱床で出る母岩・鉱物の組合せだけを`<母岩>_<鉱物>_ore`で別ブロックとして登録し、採掘の手間は母岩の硬さに合わせる。Tier 0〜2の必須資源は北西大陸に保証する（[12](12-m2-fixed-map.md)）。
- **化石燃料の品質:** 化石燃料は品質を持つ。
  - 石炭: 泥炭・褐炭・瀝青炭・無煙炭の種類と、発熱量・揮発分・灰分・硫黄分。
  - 原油: 比重（API度）と硫黄分。軽質・低硫黄ほど精製しやすい。M2では軽質/重質×低硫黄/高硫黄の4種類を別流体として登録する（[12](12-m2-fixed-map.md)）。
- **石油:** 地上の油田はほぼ枯渇しており、残存するのは深部の小規模な油層（固定位置に少数）と旧文明のタンク・ドラム缶（有限）だけ。燃料・化学原料は石炭（コークス、コールタール）、バイオマス（木材の熱分解、発酵）、後にフィッシャー・トロプシュ合成などの代替経路で賄う。ゴムは天然ゴム植物などの代替原料を用意する。

## 生物【確定】

| 種類 | 内容 |
|---|---|
| バニラのMob | 湧かせない（敵対Mob・村人など） |
| 家畜（牛・羊・豚・鶏など） | 汚染・感染して凶暴化した状態でスポーンする。科学技術で治療すれば家畜として飼える。細胞を採取して培養・品種の再生に使える。生理・感染・交配の状態を持たせるため独自の動物として実装する |
| 感染・汚染された野生動物 | 肉は汚染されており、触れる・攻撃を受けると確率で感染症に感染する |
| 危険な海洋生物 | 海に出る |
| 旧文明のアンドロイド兵 | 強力な敵。高Tierの旧文明施設（研究所・軍事施設など）の内部と周辺だけに出し、序盤地域には出さない。その1段階先の地域（序盤なら工業地帯など）には、残骸と弱い個体を少数置き、先の脅威を予告する |

詳細（種類・出現地域・強さ）は提案パッケージで設計する。

## バニラ要素の扱い【確定】

| 要素 | 扱い |
|---|---|
