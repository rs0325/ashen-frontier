# 進行（確定）

## 文明段階とメイン進行

構想のTier 0〜12とメイン進行8段階を採用する。対応は次のとおり。

| メイン進行 | Tier | 主なモジュール |
|---|---|---|
| 1. 生存基盤の確立 | 0 | primitive, survival, agriculture |
| 2. 機械文明の確立 | 1〜2 | kinetics, metallurgy, steam, vehicles |
| 3. 電化と旧文明の復元 | 3〜5 | electrical, 旧設備の修復 |
| 4. 高度な工業文明 | 6〜7 | chemistry, electronics, nuclear |
| 5. 地球軌道への進出 | 8 | aerospace |
| 6. 月・火星の開発 | 9 | aerospace, 天体ごとのモジュール |
| 7. 太陽系の産業化 | 10 | 同上 |
| 8. 旧文明の超越 | 11〜12 | 恒星間・巨大構造物 |

- 旧文明は土星圏まで有人で到達していたため、メイン進行7（木星・土星圏）までは「再発見・復元」が中心、天王星・海王星圏以降はプレイヤーが新しく開発する技術とする。
- 構想の「序盤では旧文明の機械を見つけても、電力・知識・修理部品が足りないため簡単には使えない。古い工具や単純な部品は早くから再利用できる」を採用する。

## 研究

研究ポイントを消費する方式は採らず、構想の4条件の組み合わせで解放する。

| 条件 | 例 | 判定 |
|---|---|---|
| 観測・調査 | 地質調査、化学分析、気象観測 | 観測行為やデータの取得 |
| 実験 | エンジン試験、材料試験 | 実験装置で条件を満たす運転 |
| 製造実績 | 発電機や工作機械を作った | 製作・運転の記録 |
| 旧文明の資料 | 設計図、研究記録 | 資料の入手・解読 |

- 研究ツリーはデータ駆動（データパック）で定義する。
- 解放後も、材料・設備・動力が揃わなければ作れない。
- 研究はチームで共有する【確定】（独自の最小限のチーム機能、既定は1人1チーム）。旧文明の資料はアイテムとしてではなく「チームの知識」として記録し、資料アイテムを失っても知識は残る。

## 詰み防止

構想の7項目を、すべての提案パッケージで確認する項目にする。

1. 必須の資源・施設・研究資料は確実に存在し、到達できる。
2. 必須のアイテムは再製造・修理・代替入手のいずれかが可能。
3. 宇宙船の事故などで重要な技術が永久に失われない。
4. 調査機の失敗時も再挑戦できる。
5. 必須の地域へ到達できる交通手段を保証する。
6. 研究条件はゲーム内（個人端末）で確認できる。
7. 研究に必要な情報を偶然のレアドロップだけに依存させない。

加えて次を追加する。

8. マルチプレイで他プレイヤーが先に回収しても、必須の物は全員が入手できる。
9. 有限資源（遺物、残存石油、地下水）が尽きても、時間・技術で代替経路がある。
10. 管理者向けの救済コマンドで、仕組みの不具合による詰みを回避できる。

## 宇宙進出の扱い【確定・詳細は第2期以降】

- 現実の距離・時間はそのまま再現できないため、宇宙航行は**任務**として抽象化する。打ち上げ・軌道投入・遷移は、デルタV（ツィオルコフスキーの式）・打ち上げ時期・積載量を計画画面で決め、移動自体は時間経過で表す。
- プレイヤーが建設・探索する場所（軌道上の残骸、月面、火星など）だけを独自のディメンションにする。
- **無人探査の必須化:** 天体へ進出する前に、無人探査機で環境（地形・大気・放射線・資源）を調査し、データの転送かサンプルの持ち帰りを行う必要がある。小惑星帯や宇宙ステーションのような、ただの真空の場所は除く。
- **最初の目的地:** 月より先に、地球低軌道の宇宙ステーションの残骸を目指す。
- 詳細は第2期以降に提案パッケージとして設計する。

### 旧文明の宇宙施設の残骸

| 場所 | 主な施設 | 規模・重要度 |
|---|---|---|

## 移動手段

| 段階 | 手段 |
|---|---|
| Tier 0〜1 | 徒歩、手押し車、自転車（マップが32,768四方のため、序盤から移動手段の価値が高い） |
| Tier 2 | 蒸気車両（道路）と蒸気機関車（旧鉄道の修復と組み合わせる）を同時に開発する |
| Tier 3〜5 | 電動車両、旧文明の自動車の修復 |
| Tier 6以降 | 航空機、宇宙機 |

旧文明の道路・鉄道・トンネルは、修復すればプレイヤーの物流網として使える。

### 初期大陸の資源保証（ユーザー承認 2026-11-27）

初期大陸だけでT0〜T3を完結することをM2以降の統合目標へ追加する。T3のBOM・消費量・人数・工具・最終徒歩網が確定するまでは完結を検証済みとしない。地質地域への偏在を保ち、必須8/S-Aは高度探査やT4資料なしで地表の兆候から到達できるようD4/D5を接続する。探査のTier、他大陸の量/品位/難度、仮想油/ガスと地熱/超深部/マントル/外核は別設計で、装置やTier対応は本承認から推測して確定しない。[設計12](12-m2-fixed-map.md)のD4確定・後続を参照。
