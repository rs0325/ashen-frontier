# 世界観とリアリズムの範囲（確定）

## コンセプト

> Ashen Frontier — 灰の大地から、星々の彼方へ。

荒廃・汚染された地球の固定マップで、生存基盤から文明を立て直す。化学・地質・蒸気機関から工業化・宇宙進出へ進み、旧文明が届かなかった恒星間航行と巨大宇宙工学に至る。

## 時代設定【確定】

気候・海面の値は、IPCC第6次評価報告書（AR6）の予測を基準にする。AR6の2300年の海面予測はSSP1-2.6とSSP5-8.5だけで、それぞれ0.3〜3.1 m、1.7〜6.8 m（17〜83パーセンタイル）。気温は2081〜2100年でSSP2-4.5が+2.1〜3.5 ℃、SSP5-8.5が+3.3〜5.7 ℃（産業革命前比）。旧文明は宇宙進出の経済規模から高排出寄りの経路を辿ったとし、次の値を採る。

| 項目 | 採用値 | 根拠 |
|---|---|---|
| 気温上昇 | 産業革命前比 +4 ℃（地域差は気候データ側で表す） | AR6のSSP2-4.5〜SSP5-8.5の範囲内 |
| 海面上昇 | 約+5 m | AR6のSSP5-8.5の2300年の範囲内 |

| 時期 | 出来事 |
|---|---|
| 21〜22世紀 | 温暖化の進行、海面上昇、異常気象の常態化 |
| 22〜23世紀 | 宇宙進出。地球軌道都市、月・火星基地、小惑星採掘、木星・土星圏の有人拠点。天王星・海王星圏へは無人の観測・通信基地のみ |
| 23世紀後半 | 複合的な崩壊（気候・資源枯渇・紛争・感染症・原子力事故の連鎖）。地上の石油はほぼ枯渇 |
| 約150年後 | ゲーム開始。旧文明の設備は劣化しているが一部は修復できる。宇宙には放棄された拠点が残る |

- 旧沿岸都市の一部は水没または干潟になり、水没した廃墟を探索対象にできる。
- **一日の長さ【確定】:** 気候変動による一日の延長は100年あたり数ミリ秒程度で体感できないため、観測所の記録などの設定上の情報にとどめる。

## リアリズムの範囲

| 再現する | 簡略化・対象外 |
|---|---|
| 熱・温度・圧力、蒸気の状態変化 | ブロックの構造強度・崩落（空中配置は可能。強い地震による破損だけは例外、[04](04-climate.md)） |
| 回転動力（トルク・回転数・仕事率） | 流体の厳密な流体力学（ネットワーク単位の近似） |
| 物質収支（レシピでの質量保存の目安） | 化学反応の速度論（温度・圧力・触媒を条件として扱う） |
| 地質（岩石・鉱床・地層）と資源の有限性 | 惑星スケールの距離・時間（宇宙航行は抽象化） |
| 気候・気象、緯度に応じた季節 | ブロック単位の気象計算（セル単位で集約） |
| 人体の生理・健康状態、感染症 | 医療の細部（症状・治療は段階で表す） |
| 放射能（放射性物質の減衰・線量） | 核種ごとの崩壊系列の詳細（代表核種で近似） |

簡略化は各設計文書に理由とともに記録する。

## 制約と対策【確定】

自然の脅威・汚染・低品質は、技術で対処できるようにする（地震→耐震、酸性雨→耐酸性の材料、汚染・低品質→浄化・精製）。対処できない理不尽な被害は作らない。

## トーン

- 荒廃していても絶望一色にしない。穏やかな日があるから異常気象に意味がある。
- 敵の殲滅より、環境への適応と復興が中心。
- 旧文明の記録（日誌、研究資料、案内表示）で、世界が壊れた経緯を少しずつ明かす。
