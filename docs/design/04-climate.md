# 気候と気象（確定・一部案）

構想の「固定された気候データ＋変化する気象状態の2層構造」を採用する。

## 時間【確定】

| 項目 | 値 | 備考 |
|---|---|---|
| 一日の長さ | バニラと同じ20分（設定で変更可） | |
| 一年 | 24日＝8時間（設定で5〜10時間の範囲を目安に変更可） | 現実の比率では100時間を超えるため短縮する |
| 半球 | 南半球は季節を反転 | |
| 昼の長さ | 緯度と季節で変わる（極付近では白夜・極夜） | 太陽の軌道の描画も変える（空の描画） |

- 冷却・腐敗・作物の生育・半減期など長い時間を要する現象はゲーム内時間で進め、一日の長さの設定に連動させる（既定の一日20分では現実の72倍）。
- 機械の動作・燃焼などその場の現象は、実時間（SI秒）で進める。

## 緯度ごとの季節【確定】

四季は中緯度帯だけにし、各地点はその位置にふさわしい気候にする。

| 緯度帯 | 季節の表れ方 |
|---|---|
| 赤道付近（〜約10°） | 年中高温。四季はなく、雨季・乾季がある地域もある。日中は灼熱 |
| 亜熱帯（約20〜30°） | 乾燥帯。季節の変化は小さく、日較差が大きい |
| 中緯度（約35〜55°） | 四季（各6日）。初期生存地域はここ |
| 高緯度（約60°〜） | 長い冬と短い夏。積雪・凍結・永久凍土。両端は白夜・極夜 |

## 気候（固定層）

各地点の基準気候を、緯度・仮想標高・海からの距離・地形（山脈の風下など）から計算し、マップ版ごとに固定する。

- 年平均気温: 緯度による分布＋温暖化分（+4 ℃、[01](01-vision.md)）＋気温減率（約6.5 ℃/km）
- 季節振幅・日較差: 緯度と海からの距離で決める
- 年降水量・湿度: 大気循環の帯（赤道収束帯、亜熱帯高圧帯、偏西風帯）と地形で決める
- 卓越風: 緯度帯ごとの貿易風・偏西風・極東風

## 気象（変化層）

- **気象セル:** 512ブロック四方を1セルとし（4,096セル）、気温・湿度・気圧・風・雲量・降水・粉じん・大気汚染を持つ。
- **更新:** 10〜30秒ごと。セル間で熱・水蒸気・気圧変化を簡略的に伝播させ、低気圧や前線を移動する「気象システム」として表す。
- **未ロード地域:** 同じセル計算を続ける（セル数が少ないため全域で計算できる）。
- **気温:** T = 気候 + 季節 + 日周 + 天候 + 局所（熱源・水域・標高差）。

## 天候イベントと災害【確定】

構想の砂嵐・熱波・干ばつ・酸性雨・吹雪・寒波・雷雨・暴風・濃霧を採用する。地域の気候と気象セルの状態から発生させ、全域で均等に抽選しない。

- **技術で防げる:** 被害はすべて対策技術で防げるようにする。

| 脅威 | 主な影響 | 対策 |
|---|---|---|
| 酸性雨 | 金属の腐食、作物・土壌への害 | 耐酸性の材料、屋根、土壌の中和 |
| 砂嵐 | 視界、機械の摩耗、呼吸器 | フィルター、防塵、防風壁 |
| 雷雨 | 落雷による火災・設備の停止 | 避雷針、接地 |
| 吹雪・寒波 | 凍結、配管の破裂、低体温 | 断熱、保温、不凍液 |
| 熱波・干ばつ | 熱中症、水不足、作物の枯死 | 冷却、遮光、貯水、灌漑 |
| 地震 | 震度に応じて機械の停止・位置ずれ、配管の漏れ、強い揺れでは建物の破損 | 耐震構造・免震装置・固定具 |

- **プレイヤーの操作による悪化:** 世界全体の気候は悪化させない。工場の排煙などは周辺の大気汚染として一時的に影響し、発生源を止めれば回復する。
- **閉じた空間の空気:** 室内で燃焼すると二酸化炭素・一酸化炭素がこもり、中毒の原因になる。換気・煙突で防ぐ。空間の判定は燃焼設備の設置・状態変化時に上限付きの範囲探索で行い、毎tickは行わない。
- **放射線事故:** 原子力設備の事故による汚染は局所に残留し、時間経過（減衰）と除染技術で取り除ける。

### 地震【確定・数値は案】

- **発生:** 地域の地震活動度（プレート境界・火山帯で高い）から、低頻度で発生させる。震源ごとにマグニチュード（Mw）と深さを持つ。
- **震度:** 震源からの距離・深さ・地盤（軟弱な堆積層ほど揺れやすい）から、各地点の震度を気象庁震度階級（0〜7）で求める。距離減衰は経験式を簡略化して使う。
- **影響:** 震度が大きいほど影響を強くする。
  - 中程度: 固定していない機械の停止・位置ずれ、配管の漏れ、棚の物の落下
  - 強い揺れ: 建物の破損（ガラスなど脆いブロックの破壊、耐震性の低いブロックの損傷・崩れ）を許可する
- **対策:** 耐震構造（補強材・耐震ブロック）、免震装置（その上の構造物への揺れを弱める）、機械の固定具。地震計による観測と、後の技術での早期警報。
- **思想との関係:** ブロックの構造計算は行わない（空中配置は引き続き可能）。破損は局所的な災害で、対策技術で防げる。被害の上限と無効化を設定で用意する。
- **性能:** 発生時に読み込み済みの範囲だけを対象にし、処理するブロック数に上限を設けて複数tickへ分散する。

## 設備への影響

構想の表（太陽光・風力・冷却・水回収・農業・交通・打ち上げ）を採用し、各設備の設計時に気象の入力を明記する。第1期で関係するのは、水車（河川流量・凍結）、風車（風速・強風時の停止）、ボイラー（外気温による放熱）、農業、雨水回収・太陽熱蒸留器（降水・日照）、乗り物（積雪・凍結・砂嵐）。

## 観測と予報

構想の段階的な観測技術を採用する。予報の精度は観測地点の数・センサーの精度・計算設備で変える。第1期は空の観察、風向計、温度計、気圧計、雨量計、機械式記録装置まで。

## 空の描画【確定】

設定で段階的に削れるようにしたうえで、次の水準を目標にする。

- **星空・天の川:** 宇宙Modの代表格（Galacticraftなど）と同等以上の水準。実在の星表に基づく星の位置・明るさ・色、天の川の帯。緯度と季節で見える星が変わり、汚染・粉じん・月明かりで暗い星から見えなくなる。
- **天体:** 月の満ち欠けと、肉眼で見える惑星（金星・火星・木星・土星）を軌道に沿った位置・明るさで表示する。
- **宇宙からの惑星:** 軌道上・他天体からの惑星を、表面の模様・大気の縁の光・昼夜の境界・環（土星）・満ち欠けまで細かく描く。
- **太陽:** 緯度と季節による軌道の変化（白夜・極夜）も描画で扱う。
- 描画素材は独自に作り、他Modの素材やコードは流用しない。

## 実装順

1. 基準気候（緯度・標高・海からの距離）
2. 季節と日周の気温
3. 湿度・風・降雨・降雪
4. 天候イベント
5. 農業・設備との連携
6. 観測・予報
7. 地域間の高度な気象シミュレーション
