# 自然物アセット

カタログの正本は`core/src/main/resources/catalog/nature.json`。登録・datagen・素材生成はこのファイルを読む。

岩石の粒状模様、土、液体の周期模様は固定シードのコードで生成する。その他は組込みGPT imageで生成した`source-atlas.png`を使う。プロンプトは`prompt.txt`に保存する。バニラ画像は読み込まない。

Pillow 13.0.0で`generate.py`を実行する。アトラスをセル単位に切り、BOXで16×16へ面積平均してからアルファを二値化する。最近傍だけでは細い繊維や粒を取り落とし、Lanczosでは輪郭にリンギングが出るため、面積平均を採用する。拡大した確認シートは最近傍。鉱石は母岩と、鉱物の色を付けた粒のオーバーレイを合成する。

```powershell
python tools/nature-assets/generate.py
```

流体のstillは16×16、flowは標準の流体描画が半幅をサンプリングするため32×32。アニメーションのない周期模様とする。原本は組込みGPT imageで生成した画像をそのまま保存し、元セルのアルファを維持して縮小する。再実行に画像生成APIは不要。
